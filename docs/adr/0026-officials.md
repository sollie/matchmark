# Referees and Range officers on Competitions and Matches

A Competition and a Match each hold any number of Referees and Range officers, stored in `competition_officials` and `match_officials` (parent id, role, WAID, name), with a unique constraint on parent, role and WAID. Order is not significant, the same WAID may hold both roles, and there is no cap. The four single-official columns on `matches` are replaced; the feature was never released, so `010_officials.sql` is edited in place and nothing is migrated.

A Match resolves each role live: its own officials of that role if it has any, otherwise its Competition's. Empty means inherit, so a Match cannot be set to explicitly none. Unlike the entry snapshot of ADR 0025, nothing is frozen when a Match goes active, and an admin can edit officials in any status. Someone may be swapped or added after the fact, and the documents then have to be amended, so MatchMark does not enforce a lock. Editing a Competition's officials therefore changes the results PDF of its finished Matches that inherit them, by design.

An official is any WAID found in the WA1500 register, not necessarily a user. The shooter table is checked first: a shooter with that WAID whose last refresh is older than a day is refreshed with the routine of ADR 0023 and its data is used. Otherwise, or without a shooter, the register is searched (ADR 0014). The name is stored as a snapshot on each official row, so editing a Competition list never rewrites a Match. A WAID that is not in the register answers 422 and an unreachable register answers 503; nothing is stored in either case. A Competition defaults to the signed-in user, when they have a WAID, as its Referee, and its Matches then inherit that.
