# MatchMark brand assets

Transparent SVG and PNG assets, recreated from the brand sheet (without the centre dot). The wordmark is outlined, so no font is needed. It was set in Outfit Bold (SIL OFL 1.1).

| Name | Use |
| --- | --- |
| `logo-horizontal`, `logo-stacked`, `icon` | Light backgrounds (navy and blue) |
| `*-dark` | Dark backgrounds (white and blue) |
| `*-black`, `*-white` | Monochrome |
| `favicon.svg`, `favicon-{16,32,48,64}.png`, `favicon.ico` | Favicons |

PNG sizes: horizontal 1600 px wide, stacked 1000 px wide, icon 512 px wide.

Colors: primary `#0F172A`, accent `#3B82F6`, background `#F8FAFC`, black `#000000`, white `#FFFFFF`.

Files in `public/` are served at the site root, for example `/brand/icon.svg`.
